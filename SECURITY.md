# Security policy

## Supported versions

Security support starts at version 1.0.0. We support only the latest minor
release within 1.x and ship security fixes as patch releases for that minor.
For example, after we release 1.2.0, we ship security fixes in 1.2.x, not 1.1.x.

If you use an older 1.x minor release, upgrade to the latest minor and patch.
Read the [compatibility policy](https://licence-audit.tylerbutler.com/docs/compatibility)
for the guarantees and security exceptions that apply to upgrades within 1.x.

We do not commit to security fixes for 0.x or prerelease versions.

## Report a vulnerability

Use [GitHub private vulnerability reporting](https://github.com/tylerbutler/licence_audit/security/advisories/new)
to report a suspected vulnerability in `licence_audit`. You need a GitHub
account to submit a report.

Include the affected version, steps to reproduce the problem, and its security
impact. If possible, include a small example that shows the problem without
credentials or other sensitive data.

Do not publish vulnerability details in a public issue. Use the private report
to discuss the problem and coordinate disclosure with the maintainers.
